# Mojtaba Fattah Damavandi — Portfolio

A lightweight static portfolio for GitHub Pages.

## Publish
1. Create a public repository named `mfattahi1.github.io`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:

`https://mfattahi1.github.io`

The downloadable CV is at:
`assets/Mojtaba_Fattah_Damavandi_CV.pdf`
